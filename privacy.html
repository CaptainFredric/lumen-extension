Privacy policy

Local-first capture, clear limits.

The Chrome extension is Lumen's capture app; this website is its installation and demo front door. This policy describes what the extension stores locally, how gallery, editor, and PDF-cache assets differ from downloaded originals, how timed selected-area plans work, and what happens when a user explicitly chooses a connected export.

Effective date: July 16, 2026 · Updated July 18, 2026

Default behavior

The extension stores settings, marked regions, schedules, history, compact gallery previews, bounded whole-capture editor images, and capture-time raster PDF caches on the device. Full-resolution screenshots, user-exported PNGs and PDFs, and optional supporting metadata save through Chrome Downloads.

No advertising use

Lumen keeps capture data out of personalized advertising, advertising transfers, and data sales.

Local automation stays local

Delayed, repeating, capped continuous capture, annotation, and visual comparison run locally. Only a reviewed image the user explicitly exports can be sent to the optional Google Drive destination.

Information Lumen handles

Lumen can handle the following data when you use capture, checklist, or analysis features:

  • Screenshot images of the page you choose to capture.
  • Page URL, title, host, viewport, dimensions, capture time, and export settings. Stored URLs omit fragments and common sensitive query keys such as tokens, authorization codes, session IDs, secrets, and API keys.
  • Redaction details, including detected sensitive regions and manual redaction boxes.
  • Focused-region details, including selected coordinates, dimensions, rectangle or lasso shape, lasso points, and projection status.
  • Extracted page signals such as colors, fonts, navigation labels, headline text, CTA text, and layout counts.
  • Local capture history, file names, Chrome download IDs, and supporting capture metadata.
  • Compact gallery previews and bounded whole-capture editor images stored for the local photo library. Safe-size captures can keep a lossless editor image; very large or tiled captures use a scaled whole-page proxy. These local copies do not replace downloaded originals.
  • A capture-time paginated raster PDF cache when generation succeeds. It is built from the original rendered capture output or tiles, capped at 3200 raster pixels per page, and stored locally for review export. It is not a full-resolution or searchable-text copy.
  • Optional timer-plan details, including the selected page and area, delay or repeat cadence, continuous-run cap, status, and run history.
  • Optional capture notes that you choose to add to an export.
  • Optional annotation and visual-review details, including the comparison pair, change percentage, highlighted region count, and reviewed/exported status.
  • For an explicit Drive export: the reviewed image, chosen file name, capture ID, review time, and source host.

How Lumen uses this information

Lumen uses this information to provide its user-facing capture workflow:

  • Clean sticky headers, cookie banners, chat widgets, and other page chrome before capture.
  • Generate full-page, responsive, redacted, annotated, rectangular, and transparent lasso capture artifacts.
  • Run one-time delayed, scheduled repeating, or capped continuous captures over a reviewed selected area.
  • Build a JSON metadata file that keeps capture context attached to the image outputs.
  • Show real local previews, search, filters, favorites, history, and original-file actions in the photo library.
  • Help you check redactions and focused crop resolution before export.
  • Edit arrows, text, rectangles, blur, and pixelation, use Fit, 100%, or keyboard zoom on the local working image, then export a reviewed PNG or paginated raster PDF.
  • Compare local whole-capture working images with a before/after slider, highlighted changes, statistics, and monitor timeline.

Storage and retention

Lumen stores capture history, page signals, saved regions, schedules, and capture-note drafts in local Chrome extension storage. Gallery previews, bounded whole-capture editor images, capture-time raster PDF caches, and their metadata are stored in extension-owned IndexedDB on the same device. Harmless capture preferences can use Chrome Sync; note text, screenshot images, saved regions, schedules, capture history, and cached PDFs are not placed in Chrome Sync. Full-resolution images and any enabled JSON metadata files save through Chrome Downloads into folders named by capture date.

Gallery cleanup defaults to 50 MB or 500 preview-bearing captures. Whole-capture editor sources use a separate 250 MB or 75-capture budget. Capture-time review PDFs use another separate 250 MB or 75-capture budget. Lumen removes the oldest non-favorite assets in each category first while keeping capture metadata and downloaded originals. Favorite assets are preserved. Removing a library item or clearing the library removes its local gallery image, editor source, and cached PDF; it does not delete Downloads files.

Annotation edits remain in the editor tab until PNG or PDF export or tab closure. The library stores compact review status and comparison statistics, not the editable annotation document. Editing and visual-change analysis use the local whole-capture working image when available.

Chrome extension storage, IndexedDB library images, and downloaded files use the protection provided by your browser and operating system. Lumen adds no separate encryption layer. Capture sensitive pages only when you are comfortable storing those files locally.

Sharing and transfer

This public website is an installation and demo front door, not the extension capture runtime, and it cannot capture arbitrary browser tabs. The Chrome Web Store build contains no Lumen-owned production sync endpoint. Screenshot content, photo-library images, page text, capture history, redaction details, timer-plan details, and page signals stay on the device and in downloaded files. Developers can explicitly run the repository's loopback demo backend to test session and metadata contracts on their own computer; it is not cloud storage or a production sync service. In that development path, signing in does not enable content synchronization: capture and monitor reads or writes require the separate cloud-sync control, and outbound records remove URL fragments and common sensitive query parameters while the complete scheduled target stays on-device. Team sharing, background cloud backup, full-Drive synchronization, and remote monitoring are not part of the local beta.

Google Drive export is optional and user initiated. Pressing Export to Drive after review requests Chrome's optional identity and Google API access, then uploads only that reviewed image and limited file metadata with the narrow drive.file scope. Nothing uploads merely by connecting, capturing, monitoring, comparing, or opening the editor.

Timed captures are local and opt-in. Saving one records the chosen site, selected rectangle or lasso, timing mode, cadence or delay, run cap, and permission so Chrome can capture that area while the browser is available. One-time plans run once. Continuous plans stop at the selected 10, 25, or 50 run cap. You can pause, resume, run now, or delete a plan. Deleting the last plan for a site revokes its saved access.

Limited use disclosure

Lumen uses information received from Chrome extension APIs only to provide or improve the browser capture workflow described in the product UI and listing. Lumen avoids use or transfer of that information for personalized advertising, retargeting, or interest-based advertising.

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements, and the Chrome Web Store User Data Policy. Drive authorization is used only to create reviewed files the user explicitly exports.

Human review of user capture data happens only when the user explicitly sends that data for support, review, or another chosen destination.

Your controls

  • You choose when to capture a page or explicitly save a delayed, repeating, or capped continuous selected-area plan.
  • A dedicated Settings screen controls fast capture, review-before-save, cleanup, lazy-load forcing, redaction, notes, metadata, exports, permissions, and local data.
  • On a fresh install, one-click capture starts with local-only mode and automatic redaction on, while capture-details JSON and review-before-save start off.
  • Privacy Shield is a separate stronger choice that locks review-before-save, automatic redaction, metadata minimization, and local-only behavior together and pauses unattended monitor alarms. Turning it off restores your explicit individual choices and resumes active monitors.
  • Local-only mode blocks optional connected export while leaving local PNG and raster PDF downloads available.
  • One-shot responsive site access is removed after capture when no timed capture still needs it.
  • You can remove one library item, clear the photo library and its gallery/editor images and cached PDFs, or clear local history, page signals, saved regions, note drafts, timed captures, and optional site permissions.
  • Removing local library images does not remove originals. You can delete downloaded images and metadata files separately from your Downloads folder.
  • You can clear extension storage through Chrome extension site data controls or by removing the extension.
  • You can disconnect Drive to remove Lumen's cached token and optional permissions. Previously exported Drive files remain under your control.
