Privacy policy

Local-first capture, clear limits.

Lumen captures webpages for review work. This policy describes what the extension stores locally, how downloads are saved, and how connected features handle data.

Effective date: May 12, 2026

Default behavior

The extension stores capture settings, redaction boxes, focused crop regions, extracted page signals, and capture history in the browser. Screenshot files and supporting metadata files are saved through Chrome Downloads.

No advertising use

Lumen keeps capture data out of personalized advertising, advertising transfers, and data sales.

Connected destinations stay separate

Cloud sync, agent handoff, scheduled capture, billing, and team destinations require explicit user action and clear disclosure before data leaves the browser.

Information Lumen handles

Lumen can handle the following data when you use capture, checklist, or analysis features:

  • Screenshot images of the page you choose to capture.
  • Page URL, title, host, viewport, dimensions, capture time, and export settings.
  • Redaction details, including detected sensitive regions and manual redaction boxes.
  • Focused crop details, including selected coordinates, dimensions, and projection status.
  • Extracted page signals such as colors, fonts, navigation labels, headline text, CTA text, and layout counts.
  • Local capture history, file names, Chrome download IDs, and supporting capture metadata.
  • Optional capture notes that you choose to add to an export.

How Lumen uses this information

Lumen uses this information to provide its user-facing capture workflow:

  • Clean sticky headers, cookie banners, chat widgets, and other page chrome before capture.
  • Generate full-page, responsive, redacted, annotated, and focused crop capture artifacts.
  • Build a JSON metadata file that keeps capture context attached to the image outputs.
  • Show capture history and file actions in the extension popup.
  • Help you check redactions and focused crop resolution before export.

Storage and retention

Lumen stores extension settings and local history using Chrome extension storage. Screenshot images and JSON metadata files are saved through Chrome Downloads into folders named by capture date. You control those files through your browser and operating system.

Chrome extension storage and downloaded files use the protection provided by your browser and operating system. Lumen adds no separate encryption layer. Capture sensitive pages only when you are comfortable storing those files locally.

Sharing and transfer

By default, screenshot content, page text, capture history, redaction details, and page signals stay in the browser and downloaded files. The repository includes a local demo backend for development testing.

Any cloud sync, agent handoff, team destination, or scheduled capture feature should be opt-in, visibly controlled, and described before data is sent.

Limited use disclosure

Lumen uses information received from Chrome extension APIs only to provide or improve the browser capture workflow described in the product UI and listing. Lumen avoids use or transfer of that information for personalized advertising, retargeting, or interest-based advertising.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Human review of user capture data happens only when the user explicitly sends that data for support, review, or another chosen destination.

Your controls

  • You choose when to capture a page.
  • You can disable cleanup, lazy-load forcing, redaction, notes, and metadata export in the popup settings.
  • You can delete downloaded images and metadata files from your Downloads folder.
  • You can clear extension storage through Chrome extension site data controls or by removing the extension.
