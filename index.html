Features

A better capture starts before the screenshot.

Lumen is built for the moment when a screenshot has to explain what happened and keep the page context close by.

Clean page

Clear the page before saving.

Hide sticky bars, cookie banners, ads, and chat widgets so the capture shows the page itself.

Responsive set

Save the layouts people compare.

Capture desktop, tablet, and mobile views together when the layout shift matters.

Redaction

Mark sensitive details before saving.

Find visible emails, phone numbers, tokens, and filled fields before the image leaves Chrome.

Crop
Lasso crop

Trace the useful part.

Draw around a chart, card, image, or irregular region and save that focused crop beside the page.

Timed capture

Long pages

Keep tall pages readable.

Save one image when it fits, split into tiles when it helps, or add a print sheet for PDF.

Workflow

Capture the page and the reason it matters.

A useful capture should be clean enough to share and detailed enough to understand later.

Clean

Remove the noise that gets in the way.

Lumen prepares the page by hiding common blockers and loading deferred content before the screenshot pass begins.

Capture

Save the layouts people compare.

Capture the active page, a specific device size, or a responsive set when a project needs more than one viewport.

Check

Check sensitive details before sharing.

Redaction is part of the save flow, with detected regions and manual boxes ready before saving.

Context

Keep the page signals close to the image.

The saved capture can include the page title, URL, colors, fonts, headline, CTA, and navigation labels.

Plans

Use Lumen where capture work actually happens.

Start with local clean captures. Add responsive sets, timed areas, and shared destinations when the workflow needs more structure.

Local Free

Capture a page cleanly.

Page cleanup, manual boxes, focused crops, notes, page context, and local history.

Pro

Handle multi-view review.

Responsive sets, auto-redaction, framed outputs, long-page tiles, and saved print sheets.

Team

Keep repeated captures moving.

Timed captures, shared destinations, review handoff, and longer retention controls.

Chrome Store

A Chrome Store page that shows the real product.

The listing leads with the control surface, plain permission language, and screenshots that match the extension people install.

Single purpose

Capture cleaner webpage references.

Page cleanup, responsive screenshots, redaction checks, notes, signals, and local history stay in one workflow.

Clear permissions

Capture starts from the toolbar.

Active tab access is used for the current page. Site access for responsive views is requested only when that workflow needs it.

Store page

Screenshots match the product.

The screenshots show the popup, quick actions, responsive views, and saved outputs.

Local by default

Your captures stay with you.

Lumen stores settings and history in Chrome extension storage. Image files are saved through Chrome Downloads so you control where they are stored.
