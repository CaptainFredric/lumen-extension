Privacy policy

Local-first capture, clear limits.

Lumen captures webpages for review work. This policy describes what the extension stores locally, how preview images differ from downloaded originals, how timed selected-area plans work, and what would be required before any connected feature transfers data.

Effective date: July 16, 2026

Default behavior

The extension stores settings, marked regions, schedules, history, and compact photo-library previews on the device. Full-resolution screenshots and supporting metadata save through Chrome Downloads.

No advertising use

Lumen keeps capture data out of personalized advertising, advertising transfers, and data sales.

Local automation stays local

Delayed, repeating, and capped continuous area captures run locally while Chrome is available. Cloud sharing, team destinations, remote monitoring, and billing are not part of the local beta.

Information Lumen handles

Lumen can handle the following data when you use capture, checklist, or analysis features:

  • Screenshot images of the page you choose to capture.
  • Page URL, title, host, viewport, dimensions, capture time, and export settings. Stored URLs omit fragments and common sensitive query keys such as tokens, authorization codes, session IDs, secrets, and API keys.
  • Redaction details, including detected sensitive regions and manual redaction boxes.
  • Focused-region details, including selected coordinates, dimensions, rectangle or lasso shape, lasso points, and projection status.
  • Extracted page signals such as colors, fonts, navigation labels, headline text, CTA text, and layout counts.
  • Local capture history, file names, Chrome download IDs, and supporting capture metadata.
  • Compact preview images stored for the local photo library. These are local preview copies, not replacements for downloaded originals.
  • Optional timer-plan details, including the selected page and area, delay or repeat cadence, continuous-run cap, status, and run history.
  • Optional capture notes that you choose to add to an export.

How Lumen uses this information

Lumen uses this information to provide its user-facing capture workflow:

  • Clean sticky headers, cookie banners, chat widgets, and other page chrome before capture.
  • Generate full-page, responsive, redacted, annotated, rectangular, and transparent lasso capture artifacts.
  • Run one-time delayed, scheduled repeating, or capped continuous captures over a reviewed selected area.
  • Build a JSON metadata file that keeps capture context attached to the image outputs.
  • Show real local previews, search, filters, favorites, history, and original-file actions in the photo library.
  • Help you check redactions and focused crop resolution before export.

Storage and retention

Lumen stores capture history, page signals, saved regions, schedules, and capture-note drafts in local Chrome extension storage. Compact photo-library preview blobs and their metadata are stored in extension-owned IndexedDB on the same device. Harmless capture preferences can use Chrome Sync; note text, screenshot previews, saved regions, schedules, and capture history are not placed in Chrome Sync. Full-resolution images and JSON metadata files save through Chrome Downloads into folders named by capture date.

Library preview cleanup defaults to a 50 MB or 500-preview budget. Lumen removes the oldest non-favorite preview blobs first while keeping capture metadata and downloaded originals. Favorite previews are preserved by automatic cleanup. Removing a library item or clearing the library removes local preview data only; it does not delete Downloads files.

Chrome extension storage, IndexedDB previews, and downloaded files use the protection provided by your browser and operating system. Lumen adds no separate encryption layer. Capture sensitive pages only when you are comfortable storing those files locally.

Sharing and transfer

By default, screenshot content, photo-library previews, page text, capture history, redaction details, timer-plan details, and page signals stay on the device and in downloaded files. Capture metadata can be sent only after an advanced session is active, the data-control service is reachable, and you explicitly enable cloud sync. The repository includes a local demo backend for development testing, not a production sync service.

Timed captures are local and opt-in. Saving one records the chosen site, selected rectangle or lasso, timing mode, cadence or delay, run cap, and permission so Chrome can capture that area while the browser is available. One-time plans run once. Continuous plans stop at the selected 10, 25, or 50 run cap. You can pause, resume, run now, or delete a plan. Deleting the last plan for a site revokes its saved access.

Limited use disclosure

Lumen uses information received from Chrome extension APIs only to provide or improve the browser capture workflow described in the product UI and listing. Lumen avoids use or transfer of that information for personalized advertising, retargeting, or interest-based advertising.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Human review of user capture data happens only when the user explicitly sends that data for support, review, or another chosen destination.

Your controls

  • You choose when to capture a page or explicitly save a delayed, repeating, or capped continuous selected-area plan.
  • You can disable cleanup, lazy-load forcing, redaction, notes, and metadata export in the popup settings.
  • One-shot responsive site access is removed after capture when no timed capture still needs it.
  • You can remove one library item, clear the photo library, or clear local history, page signals, saved regions, note drafts, timed captures, and optional site permissions.
  • Removing library previews does not remove originals. You can delete downloaded images and metadata files separately from your Downloads folder.
  • You can clear extension storage through Chrome extension site data controls or by removing the extension.
