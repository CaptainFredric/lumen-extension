# Historical capture fixtures

The `capture-run-*` files and `lumen-social-card.png` were generated for an older
Orbit demonstration. They remain available for historical links and regression
comparison, rather than as current product proof.

The retained JSON and ZIP may contain inferred `siteType` and `primaryCta` fields,
older viewport presets, and seeded history. These describe the old fixture.
Current captures omit those inferred fields. Existing historical bytes are kept
intact so earlier review references remain reproducible.

Current public examples use `garden-*`. Current Store examples use `store-*` and
the provenance record in `store-assets/screenshots/proof.json` in the repository.
The legacy generator is `scripts/generate-capture-artifacts.mjs`; it is separate
from both current Bug Garden pipelines.
